This is the single-cycle processor I created with VHDL in my computer architecture and assembly language class.

In the first lab, I created the single-cycle processor. In lab 2, the SCP was implemented as a hardware controller that was programmed onto an FPGA (DE10-Lite) and used to control a 7-segment display and basic robot movement. At the end of the semester in lab 3, there was a focus on building the IROM that the SCP would run, simulating the behaviors of a puppy.
